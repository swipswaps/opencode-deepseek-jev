OpenCode + DeepSeek V4.1 Flash + Jev — quick start
===================================================

1. Keys (once per machine):

       ./scripts/ensure-env.sh

   Creates .env.local (mode 0600, gitignored): API keys + server password.

2. TLS (automatic, safe to re-run):

       ./docker/certs-init.sh

   Mints machine-local docker/certs/opencode.{crt,key} for caddy
   (:4096/:5099). Also runs inside scripts/web.sh on every start.

3. Start the stack:

       ./scripts/web.sh

   Then verify:

       curl -k https://127.0.0.1:5099/api/rev
       curl -k https://127.0.0.1:4096/ -o /dev/null -w '%{http_code}\n'  # 401 = alive

   Ports are https:// only. Plain http:// answers
   "Client sent an HTTP request to an HTTPS server" by design.

4. From any machine on the mesh, use the serving host's overlay IP,
   e.g. https://10.100.0.24:5099/ and https://10.100.0.24:4096/
