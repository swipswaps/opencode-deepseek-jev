## Decisions and constraints

- No blind timer: the bound is measured from history, the early ceiling is
  disclosed, and `GATE_TIMEOUT` is the explicit operator override (RULES #91).
- No `ps`, `pgrep`, `strace`, or `inotifywait` dependency: the container has none.
  Process facts come from `/proc`; growth uses the kernel inotify API via
  `python3`, with a poll fallback.
- The container cannot prove host-only checks; it reports `SKIP (reason)` rather
  than a false failure. The host run is the confirmation step.
- `D docker/certs/.gitignore` is a read-only `empty-certs` bind-mount artifact,
  present in the current commit and `origin/main`. Do not `git rm`; `next-action`
  counts it as `masked`, not as work.
- Nothing is committed (repo policy). The working tree holds 15 modified and 5
  new paths; review before staging.

## Glossary

- **DB / store**: the SQLite database the agent writes (session history, tokens,
  cost); read-only for tooling.
- **GATE_ABORT**: the ledger row written when a harness run is interrupted, so a
  killed run is explicit instead of leaving `GATE_START` with no verdict.
- **I/O**: input/output; here, reads/writes measured in `/proc/<pid>/io` and host
  pressure.
- **inotify**: Linux file-event interface; used to timestamp log writes exactly.
- **JSON**: JavaScript Object Notation; the machine output contract (`--json`).
- **p95**: the 95th percentile of a gate's successful durations; the bound is
  twice that, so a normal slow run does not trip it.
- **PID**: process identifier.
- **PSI**: Pressure Stall Information; kernel counters for time lost waiting on
  CPU, memory, or I/O.
- **SKIP**: a check that cannot run in this environment, reported with its reason
  (never counted as PASS).
